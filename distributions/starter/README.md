# Starter Playbook

This is a small starting point for a local AI workflow playbook. It passes on
reusable boundaries, not a required copy of this repository's architecture,
tools, or process. A small local playbook is complete when it meets local
needs; it is not an unfinished upstream clone.

Start with [docs/start-here.md](docs/start-here.md). It is the Starter's only
operative guidance. Deliberately adopt only the rules that earn a place in the
local environment, and identify any local owner or reference they need.

The full AI Workflow Playbook is an optional worked example and source of
ideas, not automatic authority. To periodically review it without treating
review as synchronization or adoption, see the optional
[upstream-change review](support/upstream-change-review.md).
